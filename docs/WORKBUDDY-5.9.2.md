# WorkBuddy 5.9.2：使用原生“跟随系统”

## 使用方式

1. 在 WorkBuddy 左下角打开账户菜单，进入 **外观 / Appearance**。
2. 选择 **System / 跟随系统** 主题。
3. 在 macOS **系统设置 → 外观** 中选择 **自动**。也可以手动选择深色或浅色。

5.9.2 不需要安装本项目的 5.8.3 补丁。选择其他固定主题或自定义皮肤后，如果不再跟随系统，回到外观页重新选择 System。

## 已验证范围

2026-10-27，在一台 Mac 上，WorkBuddy 5.9.2 的外观页显示 System 已选中，保存的主题偏好为 `auto`。实际将 macOS 外观先切到深色、再切到浅色，WorkBuddy **外观设置窗口**随之变深、变浅；随后将 macOS 恢复到原先的“自动”。本次未验证所有独立窗口、皮肤和重启后场景。

从本机应用文件的静态检查中，观察到 5.9.2 存在 `follow-system` 主题标识及对应的自动模式处理；系统变化处理也会同步更新控件配色元数据。实际界面测试为以上限定范围内的运行证据。

## 对旧补丁的影响

5.9.2 的主题模块名称与存储方式改变，旧补丁仅适用于经过哈希验证的 5.8.3 文件。不要将 5.8.3 的 `original.js` 或旧补丁覆盖到 5.9.2：它们属于不同的应用版本。原有备份可以留存，不需要为本次设置而删除。

仓库当前 CLI 对 5.9.2 的 `status` 会说明有原生选项；`install`、`verify`、`uninstall` 会停止并显示引导，不声称修改或验证了运行态。5.9.2 之外的新版尚未验证，不能假定存在相同选项。

本次没有修改 5.9.2 应用资源，也没有重新签名或关闭系统安全机制。
