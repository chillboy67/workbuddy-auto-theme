# 设计与边界

## 目标

为已验证的 macOS WorkBuddy 5.8.3 恢复原生深浅色跟随。安装后不需要辅助进程持续连接应用。

## 三处行为修改

1. `getInitialTheme`：当本地 `workbuddy.autoTheme.enabled` 为字符串 `true` 时，优先用系统配色构建 `followSystem=true` 的配置，避免固定主题快照抢先生效。
2. `setTheme`：同一标记开启时，将皮肤同步传入的固定浅色 / 深色请求转换为 `auto`。原生外观卡片也会保持自动模式；希望恢复固定主题时请卸载本补丁。
3. 系统配色监听：调用 `setTheme('auto')`，让主题名及 `data-vscode-theme-kind` 等元数据重新计算。只改 `currentConfig.theme` 会遗留旧控件配色。

自定义皮肤带有独立的 `data-skin` 渲染路径。安装器发现活动皮肤时停止；安装后也不应选择这类皮肤。

## 长度与身份

受支持的模块是 `theme-B1Mw-Fbn.js`，原始长度为 10,592 字节。Electron 通过 `app.asar` 访问该 unpacked 资源时，ASAR 头仍记录原长度。直接增加文件长度可能导致读取截断和语法错误。

项目只缩短该模块中的 `[Theme]` 诊断文本，然后补齐尾部空格。诊断内容因此变简略，这是明确的取舍。输出必须同时满足长度与预期 SHA-256，否则不写入。

| 身份 | SHA-256 |
| --- | --- |
| 原版模块 | `6c27166fa8dbd8046315aff5787fde65ae06398e00d2e4dd020a509139aa27f9` |
| 补丁模块 | `e5ce8e30f0158fbd3b1d70a4545bd3890dea3bbe04c2f60d0efe4fb9e181b80e` |

ASAR 元数据保持原样。代码签名覆盖了外部资源，所以尽管不改 `app.asar`，资源签名校验仍会失效。工具不会把“未修改 ASAR”描述成“未修改安装包”或“签名不受影响”。

## 安装与恢复

```text
检查 Bundle ID / 版本 / ASAR / 哈希
  → 获得重启及修改确认
  → 创建本地原版备份和操作锁
  → 正常退出应用并写入同长度补丁
  → 临时 CDP：保存相关外观设置、开启 auto
  → 验证运行态
  → 退出调试实例，确认端口关闭，普通启动
```

已有备份必须与当前应用路径和已知原版哈希匹配；重装不会把补丁覆盖进原版备份。文件写入采用同目录临时文件加原子重命名。未知文件、路径中的符号链接以及并发操作会被拒绝。

卸载先恢复相关外观设置，再恢复原版文件，然后退出调试实例并正常打开应用。备份不会自动删除。若进程崩溃、系统断电或无法退出，`finally` 无法保证执行，需按恢复指南处理。

## 临时调试连接

CDP 只用于安装、验证、卸载。使用固定的 `127.0.0.1` HTTP / WebSocket 地址；检查目标文件 URL 和主窗口标识，不接受远端或带凭据的 WebSocket URL。端口占用时直接停止。

临时调试期间，同一台机器上的其他进程也可能访问该调试接口。完成后工具退出此实例，再正常启动应用；不会添加常驻服务或改变日常启动命令。

## 数据

工具只保存原版主题资源、补丁身份信息及安装前相关外观设置。不会导出聊天、读取登录凭据、访问账号管理接口或上传备份。安装和验证流程不请求远端服务。

CLI 的 `status --json` 会输出用户指定的应用路径和备份路径。提交问题前可将用户名及本机路径遮盖。错误信息不会打印页面异常对象或整个 DOM。

## 更新策略

没有自动更新或通用“模糊匹配”补丁。新版本需要新增明确的兼容配置、哈希、原理检查与验证记录。版本或内容不同就停止，由维护者重新适配。
